Faker Demo
----------
A demo of the Faker module, which generates realistic data such as names, emails, and date of births.

Installation
------------
Faker is not part of the standard library, so install it with pip::
    
  pip install faker

Download or clone this repository, then run the demo script::

    python demo.py

What the demo does
------------------
  * Prints five fake students with a name, email, and date of birth.
  * Prints three rows formatted as SQL INSERT values.

Requirements
------------
Python 3.9 or newer (check the Faker page on PyPI for the current minimum).
